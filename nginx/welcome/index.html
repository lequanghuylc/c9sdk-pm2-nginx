Deploy your application here

Your app replaces this page as soon as it listens on port 3000. The easiest way is automatic git deployment — start the container with:

  • GIT_REPO — https url of your repository, including an access token
  • GIT_BRANCH — optional, the default branch is used otherwise
  • DOMAIN_NAME — your domain, e.g. example.com (the IDE stays at example.com/ide)

The repository is cloned to /root/the-project and needs a deployments folder:

deployments/
  deploy.sh        # install dependencies and start the app (e.g. with pm2)
  setup-nginx.sh   # nginx config for DOMAIN_NAME
  setup-cron.sh    # optional: pull and redeploy new commits

See git-repo-example in the c9sdk-pm2-nginx repository for a complete example.

Or run something by hand

Open a terminal in the IDE and start any server on port 3000, for example:

python3 -m http.server 3000

Reload this page afterwards.
